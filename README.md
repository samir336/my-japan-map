# My Japan — 3D prefecture travel map

An interactive 3D map of Japan's 47 prefectures. Click a prefecture (or pick it from the list) to mark it as visited. Visited prefectures rise up in red.

## Features
- 3D map you can rotate, zoom and pan
- Prefecture list grouped by the 8 regions, with furigana and English names
- Search in English, hiragana or kanji
- Add your name to the title ("Samir's Japan")
- Download the full map as a PNG
- Your visited prefectures and name are saved in your browser

## Tech
A single `index.html` file. Uses three.js (loaded from a CDN) and Google Fonts. No build step.

Prefecture boundaries: [dataofjapan/land](https://github.com/dataofjapan/land).
